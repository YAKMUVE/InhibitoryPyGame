# InhibitoryPyGame

Тренажер на Python/Pygame для развития внимания, реакции и ингибиторного контроля.

Игрок видит целевой объект и клавишу, затем должен найти нужный объект среди движущихся морских существ, навести на него курсор и нажать указанную клавишу. Проект также содержит диагностический режим с таблицей Шульте и экран статистики с экспортом результатов в CSV.

## Возможности

- Основной игровой тренажер внимания и реакции.
- Дневной и ночной набор игровых объектов.
- Система очков, жизней и ошибок.
- Сохранение результатов игровых сессий в JSON.
- Экран статистики с агрегацией по датам.
- Экспорт статистики в CSV.
- Диагностический режим на основе таблицы Шульте 5x5.
- Встроенное руководство пользователя в PDF.

## Технологии

- Python 3.10+
- Pygame
- JSON для конфигурации и хранения статистики
- CSV для экспорта результатов

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/YAKMUVE/InhibitoryPyGame.git
cd InhibitoryPyGame
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать окружение:

```bash
# Windows
.venv\Scripts\activate

# Linux/macOS
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install pygame
```

## Запуск

```bash
python main.py
```

Настройки проекта находятся в файле:

```text
data/config/settings.json
```

Пример:

```json
{
  "screen_w": 1366,
  "screen_h": 768,
  "fps": 60
}
```

## Управление

В игровом режиме на экране отображаются:

- целевой объект;
- клавиша, которую нужно нажать;
- движущиеся объекты;
- количество жизней;
- текущее время игры.

Игровое действие:

1. Навести курсор на объект.
2. Нажать указанную клавишу.
3. Если объект и клавиша совпадают с целью, начисляется очко.
4. Если выбор неверный, снимается жизнь.

Используемые клавиши:

```text
SPACE, W, S, D, F, G, H, J, K, L
```

Для выхода из игрового режима используется кнопка в левом верхнем углу.

## Режимы

### Начать игру

Основной игровой режим. Игрок выбирает нужные объекты и набирает очки. При ошибках уменьшается количество жизней. После окончания игры результат сохраняется в статистику.

Сохраняемые данные:

- количество очков;
- максимальная серия фокуса;
- ошибки по объектам;
- длительность игры;
- дата и время сессии.

### Диагностика

Режим с таблицей Шульте 5x5. Нужно последовательно нажимать числа от `1` до `25`. После завершения отображается время прохождения.

### Статистика

Экран статистики показывает агрегированные результаты по датам:

- суммарные очки;
- максимальный фокус;
- максимальное время игры;
- среднее время игры;
- количество записей;
- ошибки по объектам.

Статистику можно экспортировать в файл:

```text
data/stats/export_stats.csv
```

### Руководство

Открывает файл:

```text
data/guide.pdf
```

Открытие PDF реализовано через `os.startfile`, поэтому кнопка руководства рассчитана на Windows.

## Конфигурация объектов

Дневные объекты хранятся в:

```text
data/config/entities_day.json
```

Ночные объекты хранятся в:

```text
data/config/entities_night.json
```

Пример объекта:

```json
{
  "name": "Рыба",
  "image": "fish_day",
  "size": [60, 60]
}
```

Поле `image` должно соответствовать имени `.png` файла в директории:

```text
assets/image/
```

## Данные статистики

Игровая статистика хранится в:

```text
data/stats/stats.json
```

Пример записи:

```json
{
  "score": 10,
  "max_focus": 7.42,
  "errors": {
    "fish_day": 2
  },
  "time": 45.18,
  "timestamp": "2026-07-05 20:00:00"
}
```
